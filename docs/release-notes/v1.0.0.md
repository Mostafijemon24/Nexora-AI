## Nexora AI v1.0.0 — preview

The first desktop build of Nexora AI, the LinkedIn growth and lead-intelligence workspace.

### Downloads
| System | File |
| --- | --- |
| Windows | `Nexora.AI_1.0.0_x64-setup.exe` or `Nexora.AI_1.0.0_x64_en-US.msi` |
| macOS (Apple Silicon) | `Nexora.AI_1.0.0_aarch64.dmg` |
| macOS (Intel) | `Nexora.AI_1.0.0_x64.dmg` |
| Linux | `.deb`, `.rpm` or `.AppImage` |

### What is in this build
- **Leads**: stages, contact details, tags and notes; a list with search, filters and bulk actions; a pipeline; campaigns; CSV import and export.
- **Workflows that run by themselves**: triggers (new lead, stage change, received message, post status, schedule), conditions, waits, approvals and actions, with a test run that changes nothing.
- **Reports** with rates, campaigns, messages, runs and AI usage, exportable as CSV.
- **Inbox**: new conversations, replies that show whether they were sent, tasks with real due dates.
- **Backups**: save your workspace to a file and restore from one.
- With a Nexora AI server connected: sign-in, team members and roles, two-step sign-in, several workspaces, email and WhatsApp sending and receiving, two-way sync with HubSpot, Salesforce and Google Calendar, publishing to LinkedIn, and AI through your own provider keys.
- New installer artwork, and the desktop app can check for updates once an update key is set up.

### Good to know
- This build **runs without a server** until you give it one. Activate with the key `NXR-VALID-0001`. The workspace starts empty and a short
  tour introduces each page. What you add stays on that device, and workflows run while the app is open. Nothing can be connected or sent
  without a server, and AI answers are built-in examples. To use a server, choose *Use a different server* on the first screen and enter its address.
- The installers are **not code-signed yet**; Windows and macOS show a warning the first time you open them.
- **macOS:** if the app is reported as unverified, open *System Settings → Privacy & Security* and click
  *Open Anyway*. If you see *"Nexora AI.app" is damaged and can't be opened*, click *Cancel*, move the app
  to *Applications* and run `xattr -cr "/Applications/Nexora AI.app"` once in Terminal.
