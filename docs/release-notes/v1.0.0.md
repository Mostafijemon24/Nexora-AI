## Nexora AI v1.0.0 — preview

The first desktop build of Nexora AI, the LinkedIn growth and lead-intelligence workspace.

### Downloads
| System | File |
| --- | --- |
| Windows | `Nexora.AI_1.0.0_x64-setup.exe` or `Nexora.AI_1.0.0_x64_en-US.msi` |
| macOS (Apple Silicon) | `Nexora.AI_1.0.0_aarch64.dmg` |
| macOS (Intel) | `Nexora.AI_1.0.0_x64.dmg` |
| Linux | `.deb`, `.rpm` or `.AppImage` |

### Good to know
- This is a **preview that runs on sample data**, so you can explore every screen. Activate with the key `NXR-VALID-0001`.
- The installers are **not code-signed yet**; Windows and macOS show a warning the first time you open them.
- **macOS:** if the app is reported as unverified, open *System Settings → Privacy & Security* and click
  *Open Anyway*. If you see *"Nexora AI.app" is damaged and can't be opened*, click *Cancel*, move the app
  to *Applications* and run `xattr -cr "/Applications/Nexora AI.app"` once in Terminal.
- What is not built yet is listed in [ROADMAP.md](https://github.com/Mostafijemon24/Nexora-AI/blob/main/ROADMAP.md).
